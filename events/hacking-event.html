CYBERSECURITY SESSION / 2026

Interactive Ethical Hacking

13 March 2026 · NFSU Tripura Campus
Hands-on Security

Session Overview

This practical cybersecurity session explored how real-world attacks work and why secure design matters. Participants were introduced to live demonstrations, defensive thinking and the responsible conduct required for ethical hacking.

Session Highlights

  • Live vulnerability demonstrations
  • Secure system design principles
  • Web security fundamentals
  • Defensive and ethical practices

Event Details

The session connected common attack patterns with practical prevention strategies. Demonstrations were presented as learning exercises inside a controlled environment, emphasizing authorization, responsible disclosure and technical safeguards.
